# 利用者マニュアル（管理者向け）

クリニック向けシフト作成システム（v2）の管理者UIについて、起動方法と
月次のシフト作成業務の一連の操作手順を説明する。

対象読者: シフト作成業務を行う管理者（技術的な知識は前提としない）。

## 1. 起動方法

初回起動時は仮想環境の作成・依存パッケージのインストールを自動で行うため、
やや時間がかかる（数分程度）。2回目以降はすぐに起動する。

- **Windows 10/11（本番環境）**: `scripts\run_app.bat` をダブルクリックする
- **Linux/WSL（開発環境）**: ターミナルで `bash scripts/run_app.sh` を実行する

起動後、ブラウザで <http://localhost:8501> にアクセスする（`run_app.bat` /
`run_app.sh` はブラウザを自動起動しないため、手動でアクセスすること）。

終了する場合は、起動時に開いたターミナル（黒い画面）を閉じるか、
`Ctrl + C` を押す。

## 2. 画面構成

画面左のナビゲーションから、以下の画面を切り替えられる。

| 画面 | 用途 |
|------|------|
| ホーム | トップ画面 |
| スタッフ管理 | スタッフのスキルスコア・勤務形態・週勤務日数の登録・編集 |
| 休暇入力 | 日付単位の休暇登録（終日休・午前休・午後休） |
| シフト生成 | 対象月のシフトを自動生成し、結果を表形式で表示 |
| シフト編集 | 生成結果の手動編集（制約違反があれば警告表示） |
| Excel 出力 | 月間勤務表を Excel ファイルとして出力（印刷用レイアウト） |

## 3. 月次のシフト作成手順

毎月のシフト作成は、以下の順序で行う。

### 3-1. スタッフ情報の確認・更新（「スタッフ管理」画面）

異動・入退職・スキル変更があった場合は、この画面で表を直接編集し、
「保存」ボタンを押す。変更がなければこの手順は不要。

### 3-2. 休暇の登録（「休暇入力」画面）

対象月の休暇（終日休・午前休・午後休）をスタッフごとに登録し、
「保存」ボタンを押す。休暇登録が漏れていると、その日にそのスタッフが
出勤扱いで生成されてしまうため、生成前に必ず確認する。

### 3-3. シフト生成（「シフト生成」画面）

最適化モード（バランス／スキル重視／日数重視）を選択し、
「生成実行」ボタンを押す。生成には数十秒かかる場合がある。

- 生成が成功すると、結果が表形式で表示される
- 生成できなかった場合（「シフト生成不可」と表示される）は、
  画面に表示される「要因の手がかり」（休暇の集中日・必要人数の不足）を
  確認し、3-2 の休暇登録や 3-1 のスタッフ人数を見直したうえで再実行する
- 週40時間チェックが有効な設定の場合、超過があれば警告として表示される
  （生成自体はブロックされない）

### 3-4. 手動編集（「シフト編集」画面）

生成結果を表内で直接編集できる。編集するとハード制約（人数不足・
重複配置・休暇時間帯への配置等）の違反チェックが自動で表示される。
違反があっても保存は可能（最終判断は管理者が行う）。

編集を確定する場合は「保存」ボタンを押す。この保存はブラウザの
セッション内でのみ有効（ファイルには書き込まれない）。次の 3-5 の
Excel 出力は、この保存後の最新状態を対象とする。

### 3-5. Excel 出力（「Excel 出力」画面）

印刷の向き（横／縦）と用紙サイズ（A4／A3）を選択し、
「Excel ファイルをダウンロード」ボタンを押すと、月間勤務表の
Excel ファイルがダウンロードされる。印刷して掲示する運用を想定した
レイアウトになっている。

## 4. 実データへの切り替えについて

現時点でこのシステムは、テスト用のサンプルデータ
（`config/samples/` 配下、架空のスタッフA〜E）を初期値として動作する。
実際の診療所データ（診療時間・必要人数・スタッフ情報等）を用いる場合は、
`config/schema_reference.md` の定義に従って設定ファイルを作成し、
環境変数 `CLINIC_CONFIG_PATH` / `CLINIC_STAFF_PATH` / `CLINIC_SCHEDULE_PATH`
でファイルの場所を指定する（`02-src/ui/pages/*.py` 冒頭の
`DEFAULT_*_PATH` 定義を参照）。実データの投入方法（配布形態）自体は
今後の検討事項（ARCHITECTURE.md 7章 Q-09）である。

## 5. うまくいかないときは

| 症状 | 確認事項 |
|------|---------|
| 起動スクリプトを実行してもブラウザ画面が開かない | `http://localhost:8501` に手動でアクセスする |
| 「診療所設定の読込に失敗しました」と表示される | 設定ファイルのパス・YAML の書式を確認する |
| シフト生成が「不可」になる | 画面の「要因の手がかり」を確認し、休暇の集中や必要人数の不足を解消する |
| Excel ファイルの内容がおかしい | 「シフト編集」画面で保存し忘れていないか確認する（保存前の生成直後の値が出力される） |

上記で解決しない場合は、プロジェクトオーナーへ連絡する。
